# Verb Quest — тренажёр неправильных глаголов

Интерактивный тренажёр 30 английских неправильных глаголов со встроенной озвучкой.

Открыть: https://zhannais3180-hue.github.io/irregular-verbs-trainer/

Для запуска на компьютере откройте `index.html` в браузере. Для записи голоса разрешите доступ к микрофону; доступность зависит от браузера.

`Irregular_Verbs_Trainer.html` — исходный файл тренажёра, `index.html` — его копия для GitHub Pages.
